# 紫微斗数独立排盘工具

本目录提供一个纯前端静态网页，包含《天纪》规则实验引擎与通用传统独立实验引擎。两套核心排星算法分别实现，网页可单独排盘或并排对比。

## 使用

1. 打开 GitHub Pages 网页。
2. 输入性别、出生日期、出生时间，选择公历/农历与排盘体系。
3. 点击“生成命盘”查看十二宫、星曜与规则摘要。
4. 生成后可以导出 JSON、打印/保存 PDF，并运行规则自检。

网页入口： https://zhou-litong-fly.github.io/DestinyCompass/ziwei-doushu/

## 当前功能

- **《天纪》规则实验模式**：使用 `engines/tianji-engine.js`，独立实现公开《天机道》文本中可核对的命身宫、五行局、紫微/天府、十四主星与一批辅煞星规则。
- **通用传统模式**：使用 `engines/traditional-chart.js` 与 `traditional-core.js`、`auxiliary-stars.js` 独立组装命盘。
- **双引擎对比模式**：左侧为《天纪》规则实验盘，右侧为通用传统实验盘；两侧不共享核心排星算法。
- **公历/农历转换**：由 `engines/calendar-layer.js` 调用 `lunar-javascript`，不调用 iztro。
- **闰月策略**：支持整月归下月、十五分界、整月归前月、按闰月本月处理；会校验所选农历月的实际天数。
- **晚子时策略**：支持按次日换日与保留当日。
- **真太阳时**：公历模式下填写出生地经度、出生时间与出生当日 UTC 偏移后进行近似校正。纬度仅供记录；地点文本不会自动解析坐标；历史时区/DST 不会自动识别。
- **结果输出**：十二宫命盘、原始 JSON、JSON 下载、打印/PDF 与规则自检。
- **手机布局**：包含 700px 与 390px 响应式断点；尚未在真实手机浏览器完成视觉验收。

## 独立算法模块

- `engines/core-rules.js`：天干地支、十二宫、年干四化表及基础规则。
- `engines/traditional-core.js`：五虎遁宫干、命宫/身宫、纳音五行局、紫微/天府定位、十四主星布列。
- `engines/auxiliary-stars.js`：左辅右弼、文昌文曲、禄存擎羊陀罗、天魁天钺、天马、地空地劫、火星铃星等十四颗辅煞星的基础定位。
- `engines/traditional-chart.js`：组装通用传统命盘 JSON。
- `engines/tianji-engine.js`：独立实现《天机道》文本中可核对的核心公式；不导入通用传统核心模块或 iztro。
- `engines/calendar-layer.js`：公历/农历转换、闰月有效性检查、晚子时日期处理与历法元数据。
- `engines/standard-cases.js`：可复算命宫/身宫边界案例，并对两套五行局公式进行 8640 组穷举交叉核验。
- `engines/regression-suite.js`：传统核心规则、固定紫微定位参考表与穷举边界测试。
- `engines/tianji-reference-policy.js`：记录待核验的《天纪》口径来源与状态。

## 当前测试情况

最近执行的模块级测试：

- 历法适配层：6/6 通过。
- 基础规则：12/12 通过。
- 传统核心安星：14/14 通过。
- 辅星定位：15/15 通过。
- 《天纪》规则实验引擎：8/8 通过。
- 《天纪》参考口径边界：5/5 通过。
- 独立传统命盘组装：8/8 通过。
- 统一回归套件：9676/9676 通过，其中传统核心规则 14/14、《天纪》参考口径 5/5、辅星基础定位 15/15、独立传统命盘组装 8/8、《天纪》独立规则引擎 8/8，以及 9626 项穷举检查（包括 150 个紫微星定位参考值固定表比对和 8640 组双引擎五行局交叉核验）。
- 两套五行局公式：在 8640 组有效年干支、农历月份与时辰组合中，计算结果全部一致。

网页“运行规则自检”还会执行公历/农历公开转换参考案例和标准案例套件。这些涉及外部历法库的测试需要在浏览器实际加载 `lunar-javascript` 后运行；静态语法检查不等同于浏览器运行测试。

**以上结果验证的是代码公式、结构与部分参考数据的一致性，不代表完整命盘已经通过权威命例验盘，更不代表预测准确性得到证明。**

## 尚未完成的事项与边界

1. **《天纪》完整规则仍需核实。** 《天机道》公开文本中可核对的核心公式已单独实现，但部分辅煞星、四化及晚子时口径仍需对照可靠原始课程/讲义逐条确认，不能宣称完整复现所有《天纪》规则。
2. **标准命例集还不够全面。** 当前有公开命宫/身宫边界输入和五行局公式交叉核验；仍需覆盖多年份、性别、闰月、时辰及完整星曜分布的可复算命例。
3. **通用传统引擎仍属实验版本。** 其他辅杂曜、完整四化入宫、庙旺利陷、大限流年与不同流派差异尚未全部实现。
4. **历法边界需要真实浏览器验证。** 历史时区、夏令时、真太阳时、闰月月底与换日边界仍需更多实际测试。
5. **视觉验收尚未完成。** 已对 HTML/JavaScript 做静态语法检查，并检查了手机断点与溢出相关 CSS；尚未在真实桌面/手机浏览器逐屏检查按钮、文字和命盘卡片是否重叠。

- `lunar-javascript` 公历/农历转换库及示例：https://github.com/6tail/lunar-javascript
- `iztro` 公开测试中的命宫/身宫输入被用作可复算测试样本，不作为所有流派唯一标准：https://github.com/SylarLong/iztro/blob/main/src/__tests__/astro/palace.test.ts
- 《天纪》晚子时口径的部分参考信息来自第三方项目配置，尚未由原始资料完整证明。项目明确保留这一限制，不把二手标注宣称为原始规则。

## 隐私、许可与运行

- 纯前端静态网页，不需要自建服务器或 API Key。
- 首次使用需要网络加载 `lunar-javascript`。
- 本项目没有复制第三方完整前端、断语库或大型解读数据集；继续扩展时仍需遵守依赖和参考资料的许可要求。
- 本工具仅供传统文化学习与娱乐参考，不构成对现实人生的确定性预测。
